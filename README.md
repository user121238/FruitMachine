# 欢乐水果城 · 第一视角水果机

零依赖单文件 HTML5 游戏，安卓平板浏览器直接打开即玩；也可安装 APK 版（`水果大满贯.apk`，32.5KB，Android 5.0+）。

## 界面（仿街机"欢乐城"实机）

- 顶部：**小 / 大** 翻倍键 + 跑马灯标题
- 中央：24 灯转灯盘（8 水果 × 3 灯，每灯位印水果与赔率），**盘中央大红 GO 键**即开始
- 底部：奶油色押注面板，8 个发光圆钮（水果 + 赔率）
- 中奖后赢分进入"待收"状态（赢分 LED 闪烁）：按 **大/小**（骰子 3-10 小 / 11-18 大）可反复翻倍，押注或开新局自动收取

## 运行

- **最简单**：把 `index.html` 传到平板（微信/QQ/USB 均可），用 Chrome 打开。
- **正式一点**：`python -m http.server 8765`，平板同局域网访问 `http://电脑IP:8765`。
- 打开后建议点右上角 **⛶** 进入全屏，横屏使用（竖屏会提示旋转）。

## 玩法（街机水果机规则）

- **上分**：+1000 分（金币雨特效）；**下分**：全部分数存入累计退分。
- 选筹码（1/5/10/50/100），点水果格押注，可多格同押，押注跨局保留。
- **GO / 开始**：转灯追逐 → 减速 → 停灯，压中按赔率赔付。

**开奖机制（全随机 · 纯静态权重）**：彻底剔除动态窥探玩家下注的黑箱算法，做成真正透明、完全公正的加权轮盘。每个水果变体拥有固定的静态权重 `weight`（总权重 663）：
- 🍊橙子 / 🍎苹果：高频返还（占 ~54.3%）
- 🍋柠檬 / 🔔铃铛：中频盈利（占 ~19.5%）
- 🍉西瓜 / ⭐双星：中高级奖（占 ~14.2%）
- 7️⃣幸运7：高级大奖（占 ~4.5%）
- 🍫BAR：终极大奖（占 ~2.6%）
- 🥚LUCK 特色送灯：大奖狂欢（占 ~4.5%）

**LUCK 幸运大奖模式（完整支持全部 8 大街机玩法）**：
1. 🚂 **开火车 (3~5灯)**：汽笛长鸣，车厢连续顺时针驶过相邻水果，全部累加赔付！
2. 🥉 **小三元**：精准开出 **小西瓜 + 小77 + 小双星**（各赔 ×3）。
3. 🥇 **大三元**：三大王牌 **大西瓜(×20) + 大77(×40) + 大双星(×30)** 齐爆！
4. 🍀 **小四喜**：**小橙 + 小木瓜 + 小铃铛 + 小苹果**（四项基础小变体齐开花）。
5. 👑 **大四喜**：**大橙(×10) + 大木瓜(×15) + 大铃铛(×20) + 大苹果(×5)**（四门基础大水果全中）。
6. 💥 **满天飞雨 (散弹打枪)**：突突突机关枪扫射，盘面随机击中 4 盏走灯！
7. 🍫 **送大 BAR (直捣黄龙)**：走灯戏剧性漂移锁死在 **大BAR (×120)**！
8. 🎆 **大满贯 (天龙八部)**：24 盏灯霓虹追逐，全盘通赔（保底 888 分）！


## 技术

Canvas 转灯盘（状态机：accel→cruise→decel→blink）+ 全屏粒子层（金币/火花）+ WebAudio 现场合成音效（零音频素材）。积分与待收赢分均通过 `localStorage` 实时持久化，防止切屏丢分。

## APK 打包（一键构建脚本）

工程配备了一键构建脚本 `build.ps1`，自动完成资产同步、路径隔离、编译、对齐与签名：

```powershell
# 运行一键构建（会自动拷贝至临时目录规避 aapt2 中文路径限制）：
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

输出产物将自动携带 `AndroidManifest.xml` 中的版本号与当前构建时间戳（例如 `水果大满贯_v1.5_20260903_111928.apk`），同时自动更新一份通用的 `水果大满贯.apk`（向后兼容，方便固定路径调试与安装）。

**签名密钥 `fruit-release.jks`：** 别名 `fruit`，有效期 10 年。发新版须保持密钥一致以支持覆盖安装。如需在生产环境分发，请将密钥从公开源码中移出或使用环境变量注入密码。
